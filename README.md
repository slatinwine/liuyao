# 六爻卜筮 · 算卦模拟器

一个单文件网页版六爻占卜模拟器：三枚虚拟铜钱六掷成卦，给出本卦、变卦的卦辞原文与白话简析，并按传统动爻断法给出占断。

## ✨ 功能特性

- **完整起卦流程**：三枚铜钱逐爻掷出，带旋转动画与「背 / 字」结果展示，六掷成卦
- **本卦与变卦**：自动识别老阳（九）、老阴（六）等动爻，推出变卦，双卦对照展示
- **六十四卦全数据**：内置八经卦表与 64 卦的卦辞原文 + 白话简析
- **动爻断法**：区分静卦、一爻动、两爻动、多爻齐动四种情形，按传统筮法常识给出占断建议
- **掷卦记录**：记录每一爻的少阴 / 少阳 / 老阴 / 老阳与卦象二进制代号
- **可写所问之事**：起卦前输入问题，解卦时一并展示，附占卜时间戳

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可：输入所问之事 → 点击「起卦」 → 观看六掷成卦 → 查看解卦结果，可随时「重新起卦」。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript，零依赖、零构建、单文件
- CSS 动画实现铜钱旋转与界面动效
